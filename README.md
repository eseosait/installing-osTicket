I prepared a Windows virtual machine and installed the components required to run osTicket.

### Actions Performed

- Enabled Internet Information Services (IIS)

- Installed PHP and required extensions

- Installed and configured MySQL

- Downloaded and extracted osTicket

- Copied the osTicket files into the IIS web directory

- Configured the `ost-config.php` file

- Verified that the required PHP extensions were enabled

- Completed the osTicket installation

- Confirmed access to the administrator and support portals
